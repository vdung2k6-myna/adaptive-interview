# Installing the Adaptive Interview Engine PWA

This guide explains how to install the Adaptive Interview Engine as a standalone app on your phone or tablet.

---

## Android (Chrome)

1. Open the site in **Chrome**.
2. Tap the **three-dot menu** in the top-right corner.
3. Tap **"Add to Home screen"** or **"Install app"**.
4. Confirm the prompt.
5. The app icon appears on your Home screen.

Tap the icon to launch the app in a fullscreen window without the browser address bar.

---

## iOS (Safari)

iOS does not show an install banner. Use the **Share sheet** to add the app to your Home Screen.

### Step-by-step

1. Open the site in **Safari**.

   > You must use Safari. Chrome and other browsers on iOS cannot add a site to the Home Screen in standalone mode.

2. Tap the **Share button** at the bottom of the screen.

3. Scroll down and tap **"Add to Home Screen"**.

4. Optionally edit the label. The default is **"Interviews"**.

5. Tap **"Add"** in the top-right corner.

6. The app icon now appears on your Home Screen.

### Launch

- Tap the **"Interviews"** icon.
- The app opens in a standalone window **without the Safari address bar**.
- A branded splash screen appears briefly before the app loads.

## Requirements

| Requirement | Why |
|---|---|
| HTTPS | Install prompts and service workers require a secure connection. `localhost` works for local development only. |
| Android: Chrome | Chrome is the only browser that offers the native Android install prompt. |
| iOS: Safari | Safari owns the Home Screen web app feature on iOS. |

## Troubleshooting

### Android: I do not see "Install app"

- Make sure you are using **Chrome**, not another browser.
- The site must be served over **HTTPS**.
- Try refreshing the page and waiting a few seconds. Chrome sometimes delays the install prompt.
- Open Chrome menu → **"Add to Home screen"** as a fallback.

### iOS: I do not see "Add to Home Screen"

- Make sure you are using **Safari**.
- Tap the **Share** button, then scroll the middle section of the share sheet. The option is below the AirDrop/Favorites row.
- The site must be served over **HTTPS**.

### The app still opens in Safari after adding to Home Screen

This usually happens on iOS when the site was added from a browser other than Safari, or when `apple-mobile-web-app-capable` is missing. Remove the icon and re-add it from Safari.

### Voice interview microphone does not work in the installed app

Microphone behavior in standalone/PWA mode can differ from the browser:

1. Make sure the app has microphone permission in **Settings → Safari → Microphone**.
2. If the standalone app still cannot access the microphone, open the interview link directly in **Safari** and complete it there.
3. For best results, grant microphone permission when the browser first asks.

### The splash screen or icon looks old after an update

iOS caches PWA icons and splash screens. Remove the Home Screen icon and re-add it from Safari to refresh.

## Platform Differences

| Feature | Android (Chrome) | iOS (Safari) |
|---|---|---|
| Install method | Banner or menu prompt | Share → Add to Home Screen |
| Required browser | Chrome | Safari |
| Splash screen | Android generates from icon + theme | Branded PNG splash screens |
| Offline fallback | Yes (`/offline.html`) | Yes (`/offline.html`) |
| Microphone in standalone | Usually works | Test on your device/version |

## Developer Notes

- PWA assets live in `public/` and are generated by `scripts/generate-pwa-icons.mjs`.
- Regenerate assets after brand changes:

  ```bash
  npm run pwa:assets
  ```

- The service worker (`public/sw.js`) is registered in `src/app/layout.tsx` and is stamped with a build id by `scripts/postbuild.mjs`.
- See `docs/ARCHITECTURE.md` for the full PWA/service worker design.
